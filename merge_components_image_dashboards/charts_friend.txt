EXAMPLE PATTERNS: CSS VARIABLE USAGE
═══════════════════════════════════════════════════════════════════

BAD APPROACH (Never do this):
• Using hardcoded colors like bg-white, bg-blue-600, text-gray-900
• Using hex colors like #ffffff, #3b82f6 in styles
• Hardcoding shadows, spacing, or radius values
• No use of design system tokens

GOOD APPROACH (Always do this):
• Cards: Use className="card-elevated" or className="card-glass"
• Buttons: Use className="button-primary"
• Colors: Apply style with hsl(var(--color-primary)) for backgrounds
• Shadows: Apply style with var(--shadow-xl) for box shadows
• Spacing: Apply style with var(--space-lg) for padding/margins
• Radius: Apply style with var(--radius-lg) for border radius
• Text: Apply style with var(--text-xl) for font size

PATTERN EXAMPLE - Dashboard Card:
Use className="card-elevated p-8" for the container
Add style with background using hsl(var(--color-bg-primary))
Add style with boxShadow using var(--shadow-xl)
Add hover:transform hover:scale-105 for interaction
Apply proper spacing between elements with --space-* tokens

PATTERN EXAMPLE - Primary Button:
Use className="button-primary" for instant styling
OR create custom button with:
  - background using hsl(var(--color-primary))
  - padding using var(--space-sm) and var(--space-lg)
  - borderRadius using var(--radius-lg)
  - boxShadow using var(--shadow-glow-primary)
  - transition using var(--transition-base)

PATTERN EXAMPLE - Gradient Header:
Apply style with background using var(--gradient-primary)
Use text with proper hierarchy (var(--text-4xl), var(--font-display))
Add boxShadow using var(--shadow-2xl) for elevation

Every component must use the design system consistently for professional results.
